## 身份与排序

- `paper:UUID` 为持久身份，收藏与阅读记录以它为键；`X-NNN` 是各期刊内当前排序位置。
- 分组名称去除首尾／多余空格，忽略大小写；期刊缩写与全名不会自动合并，用户可编辑统一。
- 期刊行按名称排序。行内按 YYYY、YYYY-MM 或 YYYY-MM-DD 升序，仅有年份／月份时缺少的部分以 00 比较；这不会虚构补全日期。同日期按导入时间、内部 ID 排序，未知日期最后。
- 物理 `row = 12 + 期刊索引`，`lane = 该期刊内时间索引`。左右键在同一行选论文，上下键切期刊并恢复该期刊记忆。拖动选档按实际物理 cell 还原数据，不把行列语义互换。
- 循环跨首尾沿原方向走；数据数量与渲染窗口独立。页脚刻度使用围绕当前论文的最多八个按钮，检索可按标题、作者、期刊、DOI、关键词定位。
- 未录入期刊进入独立“未录入期刊”行；空论文库不能切换进入，仍可选择文件导入。

## 识别与编辑边界

导入顺序为选择 PDF → 文件 SHA-256 查重 → PDF.js 读取 → 展示可编辑字段 → 用户保存 → 打开论文详情。已有同一文件会进入它的字段编辑，不自动再插入一份。

- 读取 PDF Info / XMP 中的标题、作者、关键词；标题缺失时从第一页较大文字回退，再回退文件名。
- 第一页中明确的机构行、期刊标签、会议声明与明确的发表日期标签可成为候选值；不会将 PDF CreationDate、文件修改时间或正文随便出现的年份当发表时间。
- Abstract 至 Introduction 之间的文字作为摘要候选。References / Bibliography / 参考文献标题之后按编号／作者起始行拆分，已知附录标题终止。
- 读取 DOI、arXiv 标识以提供论文页面。Attention Is All You Need 使用已核对的示例字段，arXiv DOI 明确标为预印本 DOI。
- 中文译名、研究领域及无法识别字段由用户填写；不执行 OCR、机器翻译、远程数据库补全。双栏文本、未规范标注的作者和参考文献可能拆分不准，均可在保存前或之后编辑。
- PDF 一次只读取一页文字，随后 cleanup；全文参考文献最多收集约 250k 字符／500 条，不为导入生成页面纹理。关闭窗口中止解析并销毁 PDF worker。保存等待 IndexedDB 事务成功，失败时保留表单。

阅读记录保存最近 12 条页码／总页数／本地时间，连续停留同页更新最近条目。阅读器里临时换入另一份未归档 PDF 时，不向原论文写入记录。

## 视觉与交互约束

- 原有字体、颜色、主场景几何、材质及档案抽取约束延续；论文库仅替换数据映射。
- PDF 限角、暗色反相、左侧切片深度、缩略图窗口、拆解与重组路径保持既有实现。
- 作者、机构、发表时间、期刊、领域、关键词处于同一滚动区；摘要、参考文献、阅读记录共用第二个滚动区。页签及底部操作栏固定，详情外层不滚动；小屏标题并入上方滚动区。
- ENTER SYSTEM 使用 top 62px；主品牌 top 52px 不变。上传入口继承主导航排版，小屏显示图标并保留触控区域。
- SAVE 与收藏 gap 4px；DOWNLOAD 使用 17×19px 的箭头／底线 SVG，gap 5px。下载直接使用原 PDF，HTTP 错误或非 PDF 响应提示失败。
