# 三行论文阵列与导航

## 2026-10-06：屏幕方向手势与分类按钮

键盘和按钮已有正确的论文／分类映射，但自由三维投影会把水平拖动同时转换为 lane 与 row，触控板横向滚动也被忽略。本次为论文库加入屏幕方向判定，保留原游戏库的自由平面逻辑。

- 横向拖动锁定 lane，保持类别；纵向拖动锁定 row，通过 `onNavigate` 恢复目标类别的选档记忆。超过 10px 且主方向达到另一方向的 1.2 倍才开始，单次手势不换轴。横向一格至少 80px、纵向一格至少 64px，避免倾斜透视把小幅上下移动放大成连续切类别。
- 原有速度估计、反向接管、持续惯性与最后吸附继续使用；惯性保持手势轴，未控制的相机轨道独立向当前选择收敛。
- 普通滚轮与触控板横向滚动切论文，Shift＋滚轮切类别。输入累积器处理像素／行／页单位、反向、切轴、切库和 180ms 超时；Ctrl＋滚轮保持原生缩放。
- 分类按钮上下排列且保持 44px 点击区；手机论文导航上移，避免与分类按钮重叠。更新键盘提示及按钮悬停、无障碍说明。

验证：

- `node --experimental-strip-types scripts/check-archive-drag.mjs`：原自由平面、帧率独立惯性、论文方向判定、斜向抖动、反向、惯性不串轴、减少动态效果通过。
- `node --experimental-strip-types scripts/check-archive-wheel.mjs`：横向滚动、Shift 类别切换、累积重置、单位及原库行为通过。
- `node scripts/check-paper-navigation.mjs`：Edge headless，1920×1080 鼠标与 390×844 CDP 触摸事件两组通过。覆盖方向键、类别记忆、横向滚动、Shift＋滚轮、横纵向拖动和手机按钮间隔；两组无 pageerror，截图已检查。环境可通过 `PLAYWRIGHT_MODULE` 指定 Playwright 模块路径，`REVIEW_URL` 指向本地 Vite 服务。沙箱中的 Edge 启动失败，最终使用沙箱外临时配置与同环境本机预览完成；未使用个人浏览器配置。

- PWA 发行 `26c737272b35dc65`：1,024 个离线资源，41.0 MiB；Cloudflare 1,032 个文件。打包结果不等于线上发布验证。上述移动验证为 Edge 视口模拟，不是真实 iPhone 或 Wallpaper Engine 宿主验收。

## 2026-09-30：三行目录与导航映射

2026-09-30，覆盖首批目录的六个期刊行。

## 定位

旧实现中，`stepFile` 在论文库切换期刊，而 `stepColumn` 选择组内论文。刻度旁 ↑／↓ 接前者，分类名旁 ←／→ 接后者，因此按钮所属区域、统计数字与实际动作相反。键盘左右本身调用了 lane 轨道，但界面两组动作容易混淆；滚轮更是始终发出 row 导航，导致轮滚只换期刊、不浏览同行论文。

另外，Scene 的坐标归一化仍按旧档案固定 5／8 周期平移，在长距离循环时会改变论文的物理格位映射。上述是本轮从代码确定的问题，不以截图推断键盘事件被纵向监听器覆盖。

## 当前规则

| 物理行／顺序 | 内容 | 数量 |
| --- | --- | ---: |
| 1 | 代表论文 | 100 |
| 2 | ACL／ICML 会议论文 | 400 |
| 3 | 近期 arXiv 论文 | 500 |

`collection` 是目录分组，不是论文 venue。由初始导入选择阶段生成并随稳定 ID 保留。每行以原有发表／提交日期精度升序，日期相同按导入时间及稳定 ID 排序；X-NNN 在行内重编。PDF URL、修订、论文身份、收藏和阅读记录不变。旧存储中的元数据编辑保留，分组从当前目录补齐。用户手动上传不冒充代表论文，另保留“个人导入”行。

- 刻度旁 ←／→、方向键左右、鼠标滚轮：改变同一物理行的 lane，row 严格保持不变，跨首尾依旧沿原方向循环。
- 分类名旁 ↑／↓、方向键上下：row 改变一格，恢复目标行上次选中的论文；循环经过第三行后继续第一行。
- 拖动及直接点击继续由同一 `fileAtCell` 映射选择物理卡片。
- 原游戏库仍是左右分类列、上下列内档案；切库时箭头、aria-label、提示文字和禁用条件一并更新。
- 长距离归一化用实际各行长度的最小公倍数（本批 2,000）与行数 3，邻近行也保持相同论文身份。个人导入造成公倍周期超过 1,000,000 时不做横向归一化，避免不安全整数／错误身份；此时仍可导航，超长距离的数值精度不作无限规模保证。
