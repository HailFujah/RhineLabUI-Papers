# 三行论文阵列与导航

2026-09-30，覆盖首批目录的六个期刊行。

## 定位

旧实现中，`stepFile` 在论文库切换期刊，而 `stepColumn` 选择组内论文。刻度旁 ↑／↓ 接前者，分类名旁 ←／→ 接后者，因此按钮所属区域、统计数字与实际动作相反。键盘左右本身调用了 lane 轨道，但界面两组动作容易混淆；滚轮更是始终发出 row 导航，导致轮滚只换期刊、不浏览同行论文。

另外，Scene 的坐标归一化仍按旧档案固定 5／8 周期平移，在长距离循环时会改变论文的物理格位映射。上述是本轮从代码确定的问题，不以截图推断键盘事件被纵向监听器覆盖。

## 当前规则

| 物理行／顺序 | 内容 | 数量 |
| --- | --- | ---: |
| 1 | 代表论文 | 100 |
| 2 | ACL／ICML 会议论文 | 400 |
| 3 | 近期 arXiv 论文 | 500 |

`collection` 是目录分组，不是论文 venue。由初始导入选择阶段生成并随稳定 ID 保留。每行以原有发表／提交日期精度升序，日期相同按导入时间及稳定 ID 排序；X-NNN 在行内重编。PDF URL、修订、论文身份、收藏和阅读记录不变。旧存储中的元数据编辑保留，分组从当前目录补齐。用户手动上传不冒充代表论文，另保留“个人导入”行。

- 刻度旁 ←／→、方向键左右、鼠标滚轮：改变同一物理行的 lane，row 严格保持不变，跨首尾依旧沿原方向循环。
- 分类名旁 ↑／↓、方向键上下：row 改变一格，恢复目标行上次选中的论文；循环经过第三行后继续第一行。
- 拖动及直接点击继续由同一 `fileAtCell` 映射选择物理卡片。
- 原游戏库仍是左右分类列、上下列内档案；切库时箭头、aria-label、提示文字和禁用条件一并更新。
- 长距离归一化用实际各行长度的最小公倍数（本批 2,000）与行数 3，邻近行也保持相同论文身份。个人导入造成公倍周期超过 1,000,000 时不做横向归一化，避免不安全整数／错误身份；此时仍可导航，超长距离的数值精度不作无限规模保证。
